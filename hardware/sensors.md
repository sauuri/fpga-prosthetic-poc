# 센서 구성

조규진 교수 연구실 (서울대 기계공학부) 방향 — 소프트 웨어러블 손 로봇 / 재활 보조

## 선택한 센서

| 센서 | 역할 | 모델 | 가격 |
|------|------|------|------|
| IMU | 손목/팔 방향 측정 | BNO055 (9축) | ~5,000원 |
| Flex Sensor | 손가락 굽힘 각도 측정 | Spectra Symbol 2.2" | 개당 ~17,000원 × 3개 |
| 저항 | Flex Sensor 전압 분배 | 10kΩ | ~2,000원 (세트) |

**총 예산: 약 60,000원**

---

## IMU — BNO055

### 선택 이유
- 9축 (가속도 + 자이로 + 지자기)
- **내장 센서 퓨전** → 쿼터니언/오일러 각도 바로 출력
- MPU-6050 대비 칼만 필터 직접 구현 불필요 → 개발 시간 단축
- 가격이 9축 중 저렴한 편

### 비교 검토
| | MPU-6050 (6축) | BNO055 (9축) |
|--|--|--|
| 센서 퓨전 | 직접 구현 필요 | 내장 |
| 출력 | 날 것 센서값 | 각도 바로 출력 |
| 확장성 | FPGA에서 퓨전 가속 가능 | 칩 내장 |

> 추후 연구가 확장되면 MPU-6050으로 교체해 센서 퓨전 자체를 FPGA에서 가속하는 방향도 가능

### PYNQ-Z2 연결
- 인터페이스: I2C
- Arduino 쉴드 커넥터 SDA/SCL 핀 직결

---

## Flex Sensor — Spectra Symbol 2.2"

### 선택 이유
- 손가락 굽힘 각도 측정
- Exo-Glove 류 재활 로봇 제어 입력에 직접 활용
- 2.2인치 = 손가락용 표준 사이즈 (4.5인치는 팔꿈치 등 대관절용)

### 구매 수량
처음엔 3개로 시작 (검지 / 중지 / 약지)

### 국내 구매처
- [아이씨뱅큐 (ICBanQ)](https://www.icbanq.com/P013130457) — 약 17,000원/개
- [가치창조기술 (VCTEC)](https://vctec.co.kr/product/%ED%9C%98%EC%96%B4%EC%A7%90-%EA%B2%80%EC%B6%9C%EC%84%BC%EC%84%9C-22-flex-sensor-22/839)
- [일렉솔루션](https://elecsolution.co.kr/product/flex-sensor-22-%ED%94%8C%EB%A0%89%EC%8A%A4-%EC%84%BC%EC%84%9C-sen0086-%EB%94%94%EC%97%90%ED%94%84%EB%A1%9C%EB%B4%87/17243)

> 중국산 저가형은 노이즈 심함 — Spectra Symbol 정품 구매 권장

### PYNQ-Z2 연결
```
3.3V ── 10kΩ 저항 ── A0 핀 (PYNQ 읽기)
                  |
             Flex Sensor
                  |
                GND
```
구부릴수록 저항값 증가 → 전압 변화 → 각도 계산

- 인터페이스: 아날로그
- Arduino 쉴드 A0~A2 핀 사용 (센서 3개 기준)

---

## 전체 연결 구성

```
PYNQ-Z2 Arduino 쉴드
├── I2C (SDA/SCL) ── BNO055
├── A0 ── Flex Sensor 1 (검지)
├── A1 ── Flex Sensor 2 (중지)
└── A2 ── Flex Sensor 3 (약지)
```
